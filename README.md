A modern, responsive **personal portfolio website** built using **React, TanStack Start, and Tailwind CSS**.

It presents my skills, projects, certifications, coding profiles and resume, and visitors can send me a message directly from the contact form.

## 🛠️ Technologies Used

- **React** – Component-based user interface
- **TanStack Start + Vite** – Application framework and build tool
- **Tailwind CSS v4** – Styling, theming and responsive layout
- **Lucide Icons** – Icon set
- **Nitro (Netlify preset)** – Deployment on Netlify
- **FormSubmit** – Sends contact form messages to my email

## ⚙️ How to Run Locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## 🚀 Deploy on Netlify

1. Push the project to a GitHub repository (files at the root)
2. In Netlify, choose **Add new site → Import from Git**
3. Build command: `npm install && npm run build`
4. Publish directory: `dist`
5. Click **Deploy**

## 📩 Contact Form Setup

1. Deploy the website and send one test message
2. Open the activation email from FormSubmit in Gmail (check spam)
3. Click the activation link
4. After that, every message arrives in my inbox

## 🎨 Customize

- **Colors and theme:** edit the `:root` and `.dark` blocks in `src/styles.css`
- **Photo and resume:** replace the files in `src/assets/`
- **Projects, skills, links:** edit the components in `src/components/portfolio/`
